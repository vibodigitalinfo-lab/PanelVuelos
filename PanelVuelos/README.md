# Panel de Vuelos ✈️

Panel de salidas de aeropuerto hecho con Java y JavaFX.

![Captura del panel](captura.png)

## Qué hace
- Muestra una tabla de salidas con vuelo, destino, hora, puerta y estado.
- Colores según el estado del vuelo

## Tecnologías
- Java 23
- JavaFX 21

## Próximos pasos
